Here's a step-by-step guide to adding a Vista Aero-style draggable popup:

Step 1 — Add the CSS (Aero Glass Style)
Paste this inside your <style> tag (after the existing body block):


/* Aero overlay backdrop */
.aero-overlay {
    display: none;
    position: fixed;
    inset: 0;
    background: rgba(0, 0, 0, 0.35);
    z-index: 999;
}

/* The popup window */
.aero-popup {
    position: fixed;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    width: 420px;
    border-radius: 8px;
    z-index: 1000;
    box-shadow:
        0 0 0 1px rgba(255,255,255,0.6),
        0 8px 32px rgba(0,0,0,0.55),
        inset 0 1px 0 rgba(255,255,255,0.8);
    overflow: hidden;
    backdrop-filter: blur(12px);
    -webkit-backdrop-filter: blur(12px);
    background: linear-gradient(
        160deg,
        rgba(180, 210, 255, 0.55) 0%,
        rgba(100, 160, 240, 0.45) 40%,
        rgba(60, 120, 220, 0.5) 100%
    );
    border: 1px solid rgba(120, 180, 255, 0.7);
}

/* Title bar */
.aero-titlebar {

Step 2 — Add the HTML (popup structure)
Paste this just before your closing </body> tag:


<!-- Aero Popup -->
<div class="aero-overlay" id="aeroOverlay">
    <div class="aero-popup" id="aeroPopup">
        <div class="aero-titlebar" id="aeroTitlebar">
            <span class="aero-title">Windows Vista</span>
            <div class="aero-close" onclick="closePopup()">&#x2715;</div>
        </div>
        <div class="aero-body">
            <p>This is your Aero glass popup. You can put any content here.</p>
        </div>
        <div class="aero-footer">
            <button class="aero-btn" onclick="closePopup()">Cancel</button>
            <button class="aero-btn" onclick="closePopup()">OK</button>
        </div>
    </div>
</div>
Step 3 — Add the JavaScript (open, close, drag)
Paste this just before your closing </body> tag, after the popup HTML:


<script>
    function openPopup() {
        document.getElementById('aeroOverlay').style.display = 'block';
    }

    function closePopup() {
        document.getElementById('aeroOverlay').style.display = 'none';
    }

    // Dragging logic
    const popup = document.getElementById('aeroPopup');
    const titlebar = document.getElementById('aeroTitlebar');
    let isDragging = false, startX, startY, origLeft, origTop;

    titlebar.addEventListener('mousedown', (e) => {
        isDragging = true;
        const rect = popup.getBoundingClientRect();
        startX = e.clientX;
        startY = e.clientY;
        origLeft = rect.left;
        origTop = rect.top;
        popup.style.transform = 'none';
        popup.style.left = origLeft + 'px';
        popup.style.top = origTop + 'px';
    });

    document.addEventListener('mousemove', (e) => {
        if (!isDragging) return;
        popup.style.left = (origLeft + e.clientX - startX) + 'px';
        popup.style.top  = (origTop  + e.clientY - startY) + 'px';
    });

    document.addEventListener('mouseup', () => { isDragging = false; });
</script>
Step 4 — Call the popup from any element
Add onclick="openPopup()" to any button, link, or element:


<button onclick="openPopup()">Open Popup</button>
Or from a link:


<a href="#" onclick="openPopup(); return false;">Click here</a>
The popup will have the frosted blue Aero gradient, a glowing title bar, a round red close orb, Aero-styled buttons, and will be draggable by the title bar. The backdrop-filter: blur gives the real glass frost effect (works in Chrome, Edge, and Firefox).
